# 42-piscine
Ma piscine à 42 Paris (Août 2026)

## Description
Ce repo contient tous les exercices et projets que j'ai réalisé durant ma piscine C à l'école 42 Paris.\n
Le principe de la piscine est d'apprendre les bases d'Unix, du langage C et la pédagogie de l'école fortement basée sur le peer-learning.\n
Nous étions sur l'intra 42next donc l'ordre et les exercices ont beaucoup changé.
